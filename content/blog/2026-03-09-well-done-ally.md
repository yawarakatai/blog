ROG Allyを買いました。中古で5万円と少し。

これを高いと思うか安いと思うかは人それぞれでしょう。

でもこの子、CPUだけでもZen4の8コアでGeekbenchでもRyzen 7 5700X3Dに迫る勢いだし、iGPUもRDNAの12CUなのでなかなかやります。（当社比）

加えて16GBのメモリと512GBのSSDも入っています。

昨今のハードウェア高騰を考えると、これだけでも下手なミニPCよりかはお買い得に見えますよね。

更にバッテリーにモニター、コントローラーまでついてきます。

こんなことが許されていいのだろうか……

それになんと言ってもこのボディー。

デスクトップともラップトップとも違う可愛らしい形状は、これがPCであったことなどたちまち忘れさせてくれるでしょう。

ガジェットに所有感を求める自分は、この独特な形状からしか得られない栄養素を接種してCO2を排出することで生活しています。

というわけで本日はAllyをちやほやする回です。



それでは恒例の、*Linux Kernelビルド大会*を始めましょう。

一番早くカーネルをビルドできたら勝ちです。

出場選手は以下のとおりです。

- Z1 Extreme (TDP  5W)
- Z1 Extreme (TDP 10W)
- Z1 Extreme (TDP 15W)
- Z1 Extreme (TDP 20W)
- Z1 Extreme (TDP 25W)
- Z1 Extreme (TDP 30W)

結果がでました。

| TDP | Time |
| --- | ---- |
| 10W |
| 15W |
| 20W |
| 25W |
| 30W |

(なお5Wは体調不良により棄権しました。)

もちろん欠点もあります。

TypeC一つしかなくて拡張性がないとか、2230のSSDしか刺せないとか、ゲーム中はバッテリーが1~2時間しか持たないとか。

あげればキリがありません。

ただこれらの問題は基本的にAliexpressの魔法があれば解決できるので、気になった人は調べてみてください。

あとタブレットで良くないとか思ったそこのあなた。

そのとおりです。
